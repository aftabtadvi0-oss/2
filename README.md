# Habibi Wear — website

Plain HTML, CSS and JavaScript. No frameworks, no build step needed.

## Files

- `index.html` — the whole page (products, prices, phone, WhatsApp, Get Directions)
- `style.css` — the design
- `script.js` — small behaviours (footer year, smooth scroll)
- `images/` — all 8 clothing photos

## Put it online

1. Upload this whole folder to a GitHub repository (keep the same file names and the `images` folder).
2. On Vercel: Add New → Project → Import the GitHub repo → Deploy.

Works the same on Netlify or GitHub Pages.
